# Attendance

Personal PWA. Install once from Safari, use offline.

## Install
1. Open https://<your-username>.github.io/attendance-app/ in **Safari** on iPhone.
2. Tap **Share** -> **Add to Home Screen** -> **Add**.
3. First launch: set the 8:30 alarm in Clock, edit your timetable.

## Weekly habit
Open the app at least every 7 days. Settings -> Export backup weekly.

## Dev (Windows)
`npm install` then `npm run dev`. Push to `main` -> auto-deploys.
